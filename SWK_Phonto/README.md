# SWK_Phonto

เว็บไซต์แกลเลอรีกิจกรรมแบบแยกเดี่ยวสำหรับ XAMPP เชื่อมรูปจาก Google Drive มี QR Code และระบบค้นหารูปด้วยใบหน้า โดยแสดงเฉพาะรูปที่ผ่านค่าความเหมือนที่ผู้ดูแลกำหนดเท่านั้น

## ความสามารถหลัก

### หน้าบ้าน

- แสดงกิจกรรมและรูปที่ซิงก์จาก Google Drive
- QR Code ประจำกิจกรรมสำหรับเปิดหน้าค้นหารูป
- ถ่ายรูปด้วยกล้องหน้าหรืออัปโหลดรูปเซลฟี
- รูปค้นหาต้องมีใบหน้าของผู้ค้นหาเพียงคนเดียว
- รองรับการตรวจใบหน้าในรูปเดี่ยวและรูปหมู่
- แสดงเฉพาะรูปในกิจกรรมเดียวกันที่ทำดัชนีแล้วและผ่านค่า similarity
- ไม่แสดงรูปทั้งหมดเป็นผลสำรองเมื่อค้นหาไม่พบ
- QR Code และลิงก์ดาวน์โหลดแยกต่อรูป
- ไม่เปิดเผยลิงก์ Google Drive ต้นฉบับ

### หลังบ้าน

- Dashboard สรุปกิจกรรม รูป การค้นหา และดาวน์โหลด
- เชื่อม Google Drive ด้วย OAuth 2.0 แบบอ่านอย่างเดียว
- เพิ่มและแก้ไขกิจกรรม
- กำหนด Google Drive Folder ID
- กำหนดค่าความเหมือนขั้นต่ำรายกิจกรรม
- เปิดหรือปิดกิจกรรมและการดาวน์โหลด
- ซิงก์รูปใหม่หรือรูปที่แก้ไขจาก Google Drive
- ทำดัชนีใบหน้าทุกคนที่ตรวจพบในภาพ
- แก้ไขชื่อระบบ ข้อความต้อนรับ และข้อความความเป็นส่วนตัว

## เทคโนโลยี

- PHP 8.2+
- MySQL หรือ MariaDB
- Apache/XAMPP
- Google Drive API v3 และ OAuth 2.0
- Python 3.10 หรือ 3.11
- Flask, DeepFace, FaceNet512 และ NumPy

## ติดตั้งบน XAMPP

1. คัดลอกโฟลเดอร์ `SWK_Phonto` ไปไว้ที่ `C:\xampp\htdocs\SWK_Phonto`
2. เปิด XAMPP แล้ว Start Apache และ MySQL
3. เปิด phpMyAdmin
4. Import ไฟล์ `database/swk_phonto.sql`
5. ตรวจค่าฐานข้อมูลใน `config/app.php`
6. เปิดเว็บไซต์ที่ `http://localhost/SWK_Phonto/`
7. เปิดหลังบ้านที่ `http://localhost/SWK_Phonto/login.php`

บัญชีผู้ดูแลเริ่มต้น:

- Email: `admin@school.local`
- Password: `12345678`

ควรเปลี่ยนรหัสผ่านก่อนเปิดใช้งานจริง

## ตั้งค่า Google Drive API

1. สร้าง Project ใน Google Cloud Console
2. เปิด Google Drive API
3. ตั้งค่า OAuth consent screen
4. สร้าง OAuth Client ID ประเภท Web application
5. เพิ่ม Authorized redirect URI:

```text
http://localhost/SWK_Phonto/admin/google-drive.php
```

6. ใส่ Client ID และ Client Secret ใน `config/app.php`
7. เข้าหลังบ้าน > Google Drive > เชื่อมต่อบัญชี Google

บัญชี Google ที่เชื่อมต้องมีสิทธิ์อ่านโฟลเดอร์รูปที่ใช้งาน

## เปิด Face Service

ติดตั้ง Python 3.10 หรือ 3.11 แล้วดับเบิลคลิก:

```text
face-service\start.bat
```

บริการจะเปิดที่:

```text
http://127.0.0.1:5055
```

ตรวจสถานะได้ที่ `http://127.0.0.1:5055/health`

## เพิ่มกิจกรรมและซิงก์รูป

1. สร้างโฟลเดอร์รูปใน Google Drive
2. คัดลอก Folder ID
3. เข้าหลังบ้าน > กิจกรรม
4. เพิ่มชื่อกิจกรรมและ Folder ID
5. กำหนด threshold ค่าเริ่มต้น `0.72`
6. บันทึกแล้วกด `ซิงก์รูป`
7. กดเริ่มซิงก์และทำดัชนีใบหน้า

รูปแคชจะอยู่ใน `storage/photos/{event_id}` ส่วนต้นฉบับยังอยู่ใน Google Drive

## QR Code บนโทรศัพท์

QR สร้างจาก Host ที่ใช้เปิดเว็บ หากสแกนจากโทรศัพท์เครื่องอื่นให้เปิดเว็บผ่าน IP ในวง LAN หรือโดเมน เช่น:

```text
http://192.168.1.20/SWK_Phonto/
```

ไม่ควรสร้าง QR จาก `localhost` เมื่อต้องการสแกนจากอุปกรณ์อื่น และระบบสาธารณะควรใช้ HTTPS

## เงื่อนไขค้นหาใบหน้า

ผลลัพธ์ถูกกรองสองชั้น:

1. Python คืนเฉพาะ Photo ID ที่ cosine similarity ถึงเกณฑ์
2. PHP ตรวจซ้ำว่ารูปอยู่ในกิจกรรมเดียวกัน มองเห็นได้ ทำดัชนีแล้ว และผ่านเกณฑ์

การรู้จำใบหน้าไม่สามารถรับประกันความถูกต้อง 100% ควรทดสอบกับรูปจริงและเพิ่ม threshold เมื่อต้องการลดโอกาสแสดงผิดคน

## ความปลอดภัยและความเป็นส่วนตัว

- Google OAuth ใช้สิทธิ์ `drive.readonly`
- ฟอร์มหลังบ้านมี CSRF token
- ฐานข้อมูลใช้ PDO prepared statements
- ตรวจ MIME type และจำกัดเซลฟี 10 MB
- Face Service เปิดเฉพาะ `127.0.0.1`
- เซลฟีชั่วคราวถูกลบหลังค้นหา
- ดาวน์โหลดผ่าน `download.php`
- ควรกำหนดนโยบายและระยะเวลาเก็บข้อมูลให้เหมาะสมกับการใช้งานจริง
