# SWK_Phonto

เว็บไซต์เดี่ยวสำหรับรับรูปกิจกรรมจาก Google Drive พร้อม QR Code และค้นหารูปด้วยใบหน้า โดยแสดงเฉพาะรูปที่ผ่านค่าความเหมือนเท่านั้น ไม่มีการเชื่อมโยงกับเว็บไซต์โรงเรียนหรือระบบอื่น

## ความสามารถ

- หน้าแรกและอัลบั้มกิจกรรมจาก Google Drive
- QR เข้าหน้าค้นหาและ QR ดาวน์โหลดแต่ละรูป
- ถ่ายรูปหรืออัปโหลดเซลฟีจากโทรศัพท์
- ตรวจใบหน้าในรูปเดี่ยวและรูปหมู่
- แสดงเฉพาะรูปในกิจกรรมเดียวกันที่ผ่าน threshold
- หลังบ้านจัดการกิจกรรม รูป การเชื่อมต่อ Drive ผู้ใช้ การตั้งค่า และประวัติ
- ซ่อนรูปและสั่งทำดัชนีใหม่
- Google OAuth 2.0 แบบ `drive.readonly`
- เซลฟีถูกลบหลังประมวลผล

## ติดตั้งบน XAMPP

1. วางโฟลเดอร์ที่ `C:\xampp\htdocs\SWK_Phonto`
2. เปิด Apache และ MySQL
3. Import `database/swk_phonto.sql` ผ่าน phpMyAdmin
4. ตรวจค่าฐานข้อมูลใน `config/app.php`
5. เข้าเมนูหลังบ้าน > Google Drive แล้วกรอก Client ID และ Client Secret จากหน้าเว็บ
6. ตั้ง Authorized redirect URI ใน Google Cloud เป็น `http://localhost/SWK_Phonto/admin/google-drive.php`
7. ติดตั้ง Python 3.10 หรือ 3.11 แล้วเปิด `face-service\start.bat`
8. เปิด `http://localhost/SWK_Phonto/`
9. เข้าหลังบ้านที่ `http://localhost/SWK_Phonto/login.php`

บัญชีเริ่มต้น: `admin@swk.local` / `12345678`

ควรเปลี่ยนรหัสผ่านและ `FACE_SERVICE_TOKEN` ก่อนใช้งานจริง โดยค่าฝั่ง PHP และ Face Service ต้องตรงกัน

## การใช้งาน

1. เชื่อม Google Drive ในหลังบ้าน
2. เพิ่มกิจกรรมแล้ววาง Folder ID หรือลิงก์โฟลเดอร์ Google Drive ระบบจะแยก ID ให้อัตโนมัติ
3. กดซิงก์เพื่อดาวน์โหลดแคชและทำดัชนีใบหน้า
4. เปิดหน้า QR ของกิจกรรมเพื่อพิมพ์
5. ผู้ใช้สแกน QR ถ่ายรูป และรับเฉพาะรูปที่ใบหน้าผ่านเกณฑ์

## QR บนโทรศัพท์

อย่าเปิด QR จาก `localhost` หากโทรศัพท์เป็นคนละเครื่อง ให้เปิดเว็บผ่าน IP เครื่องเซิร์ฟเวอร์ เช่น `http://192.168.1.20/SWK_Phonto/` หรือใช้โดเมน HTTPS

## หมายเหตุ

การรู้จำใบหน้าไม่แม่นยำ 100% ควรทดสอบกับรูปจริงและเพิ่ม threshold หากมีผลผิดคน รูปย้อนแสง ใบหน้าเล็ก หน้ากาก หรือมุมเอียงอาจทำให้ไม่พบรูป
