# SWK_Phonto

เว็บไซต์แกลเลอรีกิจกรรมสำหรับ XAMPP เชื่อมรูปจาก Google Drive มี QR Code สำหรับเข้าหน้าค้นหาและดาวน์โหลด และค้นหารูปด้วยใบหน้าโดยแสดงเฉพาะภาพที่ผ่านค่าความเหมือนที่ผู้ดูแลกำหนด

## ความสามารถหลัก

### หน้าบ้าน

- แสดงกิจกรรมและรูปล่าสุดที่ซิงก์จาก Google Drive
- หน้าอัลบั้มแยกตามกิจกรรม
- QR Code ประจำกิจกรรมสำหรับเปิดหน้าค้นหาด้วยใบหน้า
- ถ่ายรูปด้วยกล้องโทรศัพท์หรือเลือกรูปเซลฟี
- รูปเซลฟีต้องมีใบหน้าผู้ค้นหาเพียงคนเดียว
- แสดงเฉพาะรูปที่อยู่ในกิจกรรมเดียวกัน ทำดัชนีแล้ว และมีค่าความเหมือนถึงเกณฑ์
- รองรับการค้นหาในรูปเดี่ยวและรูปหมู่
- QR Code ประจำรูปและลิงก์ดาวน์โหลดที่ไม่เปิดเผย Google Drive URL
- ลบไฟล์เซลฟีชั่วคราวหลังประมวลผล

### หลังบ้าน

- Dashboard แสดงจำนวนกิจกรรม รูป การค้นหา และดาวน์โหลด
- ตรวจสถานะ Google Drive และ Face Service
- เชื่อม Google Drive ด้วย OAuth 2.0 แบบอ่านอย่างเดียว
- เพิ่มและแก้ไขกิจกรรม
- กำหนด Google Drive Folder ID
- กำหนดค่าความเหมือนขั้นต่ำของแต่ละกิจกรรม
- เปิดหรือปิดกิจกรรมและการดาวน์โหลด
- ซิงก์ไฟล์ใหม่หรือไฟล์ที่แก้ไขจาก Google Drive
- ทำดัชนีใบหน้าทุกคนที่ตรวจพบในภาพหมู่
- แก้ไขชื่อระบบ ข้อความต้อนรับ และข้อความความเป็นส่วนตัว

## เทคโนโลยี

- PHP 8.2+
- MySQL หรือ MariaDB
- Apache/XAMPP
- Google Drive API v3 และ OAuth 2.0
- Python 3.10 หรือ 3.11
- Flask, DeepFace, FaceNet512 และ NumPy

## 1. ติดตั้งบน XAMPP

1. คัดลอกโปรเจกต์ไปที่ `C:\xampp\htdocs\school-system`
2. เปิด XAMPP แล้ว Start Apache และ MySQL
3. เปิด phpMyAdmin
4. Import ไฟล์ `database/swk_phonto.sql`
5. ตรวจการเชื่อมต่อฐานข้อมูลที่ `config/app.php`
6. เปิด `http://localhost/school-system/`

ค่าเริ่มต้นใน `config/app.php` ใช้ฐานข้อมูลดังนี้

```php
const DB_HOST = '127.0.0.1';
const DB_NAME = 'swk_phonto';
const DB_USER = 'root';
const DB_PASS = '';
```

กรณีเปลี่ยนชื่อโฟลเดอร์เว็บไซต์ ต้องแก้ `BASE_URL` และ `GOOGLE_REDIRECT_URI` ให้ตรงกัน

## 2. บัญชีผู้ดูแลเริ่มต้น

เมื่อ Import ฐานข้อมูลแล้วเปิดเว็บไซต์ครั้งแรก ระบบจะสร้างผู้ดูแลให้อัตโนมัติ

- Email: `admin@school.local`
- Password: `12345678`

ควรเปลี่ยนค่ารหัสผ่านเริ่มต้นใน `config/app.php` ก่อนเปิดใช้งานจริง หรือเพิ่มหน้าจอเปลี่ยนรหัสผ่านก่อนนำขึ้นระบบสาธารณะ

## 3. ตั้งค่า Google Drive API

1. เปิด Google Cloud Console
2. สร้าง Project
3. เปิดใช้งาน Google Drive API
4. ตั้งค่า OAuth consent screen
5. สร้าง OAuth Client ID ประเภท Web application
6. เพิ่ม Authorized redirect URI ให้ตรงกับค่าต่อไปนี้

```text
http://localhost/school-system/admin/google-drive.php
```

7. ใส่ Client ID และ Client Secret ใน `config/app.php`

```php
const GOOGLE_CLIENT_ID = 'CLIENT_ID';
const GOOGLE_CLIENT_SECRET = 'CLIENT_SECRET';
```

8. เข้าหลังบ้านและเปิดเมนู Google Drive
9. กดเชื่อมต่อบัญชี Google

บัญชี Google ที่เชื่อมต้องมีสิทธิ์อ่านโฟลเดอร์รูปที่นำมาใช้

## 4. เปิด Face Service

ติดตั้ง Python 3.10 หรือ 3.11 แล้วดับเบิลคลิกไฟล์

```text
face-service\start.bat
```

สคริปต์จะสร้าง `.venv` ติดตั้ง dependencies และเปิดบริการที่

```text
http://127.0.0.1:5055
```

การเรียกใช้งานครั้งแรกอาจมีการดาวน์โหลดโมเดล FaceNet512 จากแพ็กเกจ DeepFace

ทดสอบสถานะได้ที่

```text
http://127.0.0.1:5055/health
```

## 5. เพิ่มกิจกรรมและซิงก์รูป

1. สร้างโฟลเดอร์รูปใน Google Drive
2. คัดลอก Folder ID จาก URL ของโฟลเดอร์
3. เข้าหลังบ้าน > กิจกรรม
4. เพิ่มชื่อกิจกรรมและ Folder ID
5. ตั้งค่าความเหมือนขั้นต่ำ ค่าเริ่มต้นคือ `0.72`
6. กดบันทึก
7. กด `ซิงก์รูป`
8. กดเริ่มซิงก์และทำดัชนีใบหน้า

รูปจะถูกเก็บเป็นแคชใน `storage/photos/{event_id}` ส่วนไฟล์ต้นฉบับยังอยู่ใน Google Drive

## 6. การใช้งาน QR Code

QR Code สร้างจาก Host ที่ใช้เปิดเว็บไซต์ในขณะนั้น หากต้องการให้โทรศัพท์เครื่องอื่นสแกนได้ ต้องเปิดเว็บไซต์ผ่าน IP ในวง LAN หรือโดเมน เช่น

```text
http://192.168.1.20/school-system/
```

ไม่ควรเปิดหน้าสำหรับพิมพ์ QR ผ่าน `localhost` เพราะโทรศัพท์จะตีความว่าเป็นเครื่องของโทรศัพท์เอง

สำหรับระบบสาธารณะควรใช้ HTTPS

## 7. เงื่อนไขการค้นหาใบหน้า

ผลลัพธ์จะถูกกรองสองชั้น

1. Python Face Service คืนเฉพาะ Photo ID ที่ cosine similarity ถึงเกณฑ์
2. PHP ตรวจซ้ำว่ารูปอยู่ในกิจกรรมเดียวกัน มองเห็นได้ ทำดัชนีแล้ว และ similarity ถึงเกณฑ์

ระบบจะไม่แสดงรูปทั้งหมดเป็นผลสำรองเมื่อค้นหาไม่พบ

การรู้จำใบหน้าไม่สามารถรับประกันความถูกต้อง 100% ภาพย้อนแสง ใบหน้าเล็ก หน้ากาก มุมเอียง หรือความละเอียดต่ำอาจทำให้ไม่พบรูปหรือเกิดผลคลาดเคลื่อนได้ ควรทดสอบกับภาพจริงของงานและปรับ threshold ให้เหมาะสม โดยเพิ่มค่า threshold หากต้องการลดโอกาสแสดงผิดคน

## 8. ความปลอดภัยและความเป็นส่วนตัว

- Google OAuth ใช้สิทธิ์ `drive.readonly`
- ฟอร์มหลังบ้านมี CSRF token
- SQL ใช้ PDO prepared statements
- ตรวจ MIME type และจำกัดขนาดเซลฟี 10 MB
- Face Service ฟังเฉพาะ `127.0.0.1`
- เซลฟีถูกลบใน `finally` หลังค้นหา
- QR ดาวน์โหลดผ่าน `download.php`
- โฟลเดอร์ข้อมูล embedding ถูกปิดการเข้าถึงผ่าน Apache
- ควรกำหนดนโยบายความเป็นส่วนตัว ระยะเวลาเก็บข้อมูล และการยินยอมให้สอดคล้องกับการใช้งานจริง
