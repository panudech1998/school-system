# SWK Attendance Web (prototype)
เว็บไซต์แยกสำหรับเช็คชื่อรายวัน PHP 8+ / PDO MySQL / HTTPS.
ยังไม่เชื่อมฐานข้อมูลจริง เนื่องจากไม่มี schema ต้นฉบับ
1. ตรวจชื่อฐานข้อมูลและตารางนักเรียนจริง สำรองฐานข้อมูลก่อนติดตั้ง
2. ตรวจว่า swk_attendance_web ไม่ชนตารางเดิม แล้วรัน schema.sql ในฐานข้อมูลที่เลือก
3. สร้างบัญชีฐานข้อมูลเฉพาะ ให้ SELECT เฉพาะแหล่งรายชื่อนักเรียน และ SELECT, INSERT, UPDATE เฉพาะ swk_attendance_web ไม่ให้สิทธิแก้ตารางเดิม
4. คัดลอก config.example.php ไปนอก web root ตั้ง environment SWK_ATTENDANCE_CONFIG ใน Apache และกรอก DSN, บัญชีฐานข้อมูล, operator และ password_hash จาก PHP password_hash()
5. กำหนด student_query เป็น SELECT จากโครงสร้างจริง ให้คืน id (รหัสคงที่ไม่ซ้ำและใช้ตัวอักษร/ตัวเลขปลอดภัยสำหรับชื่อช่อง HTML), name, grade, room, number และกรองนักเรียนลาออก/พ้นสภาพ ไม่ควรใช้ข้อมูลจริงใน repository สาธารณะ
6. วาง index.php ในโฟลเดอร์เว็บแยก เปิดผ่าน HTTPS เท่านั้น จำกัดการเข้าถึงเครือข่ายโรงเรียน และตั้ง rate limit หน้า login ที่ reverse proxy
7. ทดสอบกับฐานข้อมูลจำลองก่อนใช้จริง: เลือกห้อง, บันทึก, โหลดซ้ำ, แก้สถานะ, ป้องกัน POST ข้ามห้อง, ตรวจสิทธิ DB
ข้อจำกัด: รุ่นต้นแบบเช็คชื่อรายวันเท่านั้น ใช้บัญชีผู้ปฏิบัติงานแยกหนึ่งบัญชี มีสิทธิเห็นทุกห้อง ยังไม่มีการเชื่อมบัญชีครูเดิม รายวิชา กิจกรรม หรือ Excel และยังไม่ได้ทดสอบกับฐานข้อมูลจริง ช่องยังไม่เช็คจะไม่ลบรายการที่บันทึกแล้ว
